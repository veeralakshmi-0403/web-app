# TNHB Palai Phase VII Web App

This project is a React + TypeScript + Vite application for viewing the TNHB Palai Phase VII plot data.

## Run the application

From the project root, open a terminal and run:

```bash
cd web-app
npm install
npm run dev
```

Then open the local URL shown in the terminal, usually:

```text
http://localhost:5173
```

## Build for production

```bash
cd web-app
npm run build
```

The production files will be generated in the `dist` folder.

## Preview the production build

```bash
cd web-app
npm run preview
```

If you need to stop the dev server, press `Ctrl + C` in the terminal.
